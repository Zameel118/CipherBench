1 · What CipherBench is

CipherBench is a client-side encode/decode workbench built for CTF players and SOC / DFIR analysts. You paste a payload, arm an ordered recipe of transforms, and read live output with flag highlighting - without uploading secrets to a server.

CTF mode

Chain Base64, hex, XOR brute-force, ROT/Caesar, gzip, and flag hunting until FLAG{'{...}'} appears.

SOC mode

Triage JWTs, PowerShell -EncodedCommand, MIME headers, IOCs, and defang/refang for safe sharing.

Privacy first

All crypto and parsing runs in your browser. Shared recipes never include pasted input.

2 · What makes it special

  • Recipe engine - composable stages with params, reorder, and live re-run.
  • Magic detect - heuristic suggestions appear beside Input when encodings are likely.
  • Flag radar - configurable regex with ReDoS guards, scan limits, and a timeout worker for highlighting.
  • Brute-force guards - size caps on XOR / chain brute force so a multi-MB paste cannot freeze the tab.
  • Share without leak - JSON / URL / download export of ops only; optional local history.
  • CTF UI - monospace chrome, mint terminal themes (including Cursor-style Dark/Light Modern + High Contrast), smooth menus.
  • Docker + GitHub Pages - same static build for local nginx or project Pages.

4 · Recommended SOP

  1. Paste ciphertext, logs, JWT, or PS blob into Input (or load a Sample).
  2. Review // detect chips; click to arm a likely decode.
  3. Add more ops from Operations; expand a recipe step to tune params (alphabet, XOR key, JWT secret).
  4. Press Run (or leave Auto on) and watch Output + flag highlights.
  5. Use IOC / Find Flags ops when hunting indicators.
  6. Share the recipe or Download output for your notes - never share raw sensitive input via URL.

5 · Tool catalog (high level)

Encoding

Base64 (std / URL-safe), Hex, URL, binary↔text, case / reverse / whitespace helpers.

Encryption / transforms

XOR (single-byte / repeating / optional 256-key brute force), ROT13 / Caesar with shift brute force.

Hashing

MD5, SHA-1, SHA-256 via vetted crypto-js (analysis helpers, not for new password storage).

CTF tools

Find Flags · Brute-Force Decode Chains (Base64 / hex / URL / gzip / XOR paths ranked by flag confidence).

SOC tools

JWT decode + optional HS* verify · PowerShell -EncodedCommand · MIME header decode · IOC extract · Defang / Refang.

6 · Security & trust model

  • No default backend - processing is local.
  • CSP meta tag limits script/style/connect/worker sources.
  • Flag regex validation + match budgets + worker timeout reduce ReDoS risk.
  • Large-input cutoff for automatic brute-force paths.
  • Chunked String.fromCharCode avoids stack overflows on big buffers.
  • Shared links encode recipe structure only.
