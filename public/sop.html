Standard operating procedures

CipherBench is a client-side encode/decode workbench for CTF players and SOC / DFIR analysts. Paste a payload, arm an ordered recipe of transforms, and read live output with flag highlighting - without uploading secrets to a server.

privacy local-only recipe chainable detect magic flags regex+ soc jwt · ps · ioc

// operations

Searchable arsenal. Categories accordion-open; click an op to append it to the recipe.

// recipe

Numbered stages. Expand for params, drag to reorder, remove with ×. Drop zone hints next step.

// input · output

Paste raw signal; live decode below. Flag regex, copy, download, wrap toggle on output.

Header: Auto (live re-run), Share (export/import), Theme, SOP (this page), ? tour, Run (Ctrl+Enter). Footer shows ops armed, chars, bytes, and last run ms.

  1. Paste ciphertext, logs, JWT, or PowerShell blob (or use Sample ▾ / File drop).
  2. Read magic chain chips under Input - click to arm a full multi-step recipe.
  3. Add more ops from Operations; expand recipe steps to set alphabet, XOR key, JWT secret, etc.
  4. Leave Auto on, or hit Run after edits.
  5. Check Output + flag highlights; use Find Flags / IOC Extract when hunting.
  6. Share the recipe or Download output - never put secrets in a URL.

Magic chains

Multi-step recipe suggestions (Base64→Gunzip, JWT, HTML entities, JSON Path, …) with score %. Click to load the full chain.

File drop

Open or drag a file onto Input. Text loads as UTF-8; binary loads as latin1 and arms Hex Dump. Magic bytes labeled when known.

Fork / Diff

Capture Output as a fork baseline; Diff shows line-level changes vs the current result. Also available from Share.

Named library

Save named recipes on-device (separate from recent history) and reload from Share.

Case report

Export Markdown with recipe, input, output, flag pattern, and fork snapshot. Print to PDF from any Markdown viewer.

Workers

XOR single-byte brute and large hash digests offload to Web Workers when available.

Entropy badge

H≈ Shannon entropy on Input helps spot high-entropy blobs (XOR / compressed) vs plain encoding.

Flag radar

Configurable regex with nested-quantifier / alternation rejection, scan length caps, match limits, and a worker timeout so bad patterns cannot freeze the UI.

XOR

Single-byte or repeating-key XOR. Optional single-byte brute force tries all 256 keys (Web Worker when available), ranks by printable ratio. Large inputs are blocked in brute mode.

ROT13 / Caesar

Shift A–Z / a–z. Use shift 13 for ROT13, or enable brute-force of all non-zero shifts.

AES Encrypt/Decrypt

AES-CBC + PKCS7 via crypto-js. Key/IV as UTF-8 or hex; ciphertext is Base64. For CTF / lab use - not a substitute for authenticated encryption in production.

RC4

Classic stream cipher (crypto-js Base64 ciphertext). Useful for legacy malware / CTF blobs.

Fingerprint strings for IOC matching, challenge verification, or comparing dumps. Large digests use a Web Worker when available. HMAC-SHA256/SHA1/MD5 with a secret key. Implemented via crypto-js - not for storing new passwords.

Find Flags

Lists substrings matching the configured flag pattern (default CTF-style [A-Za-z0-9_]+\{[^}]+\}). Same engine powers Output highlighting.

Brute-Force Decode Chains

Tries preset paths (Base64, URL-safe Base64, hex, URL, Base64→hex, hex→Base64, Base64→gzip, Base64→XOR brute) and ranks hits that contain flag-shaped strings by confidence + printability. Use when you know “something is encoded” but not which stack.

OpFunction
JWT DecodeBase64url header/payload pretty-print. Optional HMAC verify (HS256/384/512) with a secret you supply - timing-safe compare.
PowerShell -EncodedCommandUTF-16LE + Base64 encode/decode for LOLBin triage. Decodes opaque command-line blobs into readable script.
MIME Encoded-WordDecode RFC 2047 =?charset?B/Q?...?= header fragments from phishing mail.
IOC ExtractorPull IPv4, domains, URLs, MD5/SHA1/SHA256, emails from unstructured text into labeled sections.
Defang / RefangSafe sharing of URLs/IPs (hxxp, [.]) and reverse for analysis.
  • No default backend - transforms run in the browser.
  • CSP - meta policy locks script/style/connect/worker to self (+ fonts).
  • ReDoS defenses - pattern shape checks, scan/match budgets, worker timeout for highlighting.
  • DoS size caps - brute-force paths refuse oversized inputs.
  • Stack-safe strings - chunked fromCharCode for large XOR / PS payloads.
  • Share hygiene - JSON/URL exports exclude input text.

Already strong vs CyberChef

  • SOC-first ops (JWT verify, PS EncodedCommand, MIME, defang, IOC) in one deck
  • Flag-aware UI (highlight + detector + chain ranking)
  • Hardened client UX (ReDoS / size guards, CSP, no-input share links)
  • Modern CTF chrome with themes and guided SOP/tour
  • CyberChef-class codecs: Gzip/Zlib/Deflate, Base32/58/85, HTML entities, Punycode
  • AES-CBC, RC4, HMAC; Hex Dump + magic bytes; Regex Extract / Find-Replace / JSON Path
  • Magic multi-step chains, file drop, named library, fork/diff, Markdown case report
  • Web Workers for XOR brute and large hashes
