CipherBench — manual function test samples
==========================================
How to use:
1. Open http://127.0.0.1:5173/ (prefer 127.0.0.1 over "localhost" if UI looks stale).
2. Clear the recipe (Reset), paste ONE sample into Intel Ingest.
3. Add the named op from Arsenal, set params if noted, then Run chain (Ctrl+Enter).
4. Check Decrypted Output against the EXPECTED line.

Tip: test one op at a time. Use Transmit only after a recipe works if you want a share link.


---------------------------------------------------------------------------
ENCODING
---------------------------------------------------------------------------

### From Base64
INPUT:
SGVsbG8gQ2lwaGVyQmVuY2g=
EXPECTED:
Hello CipherBench

### To Base64
INPUT:
Hello CipherBench
EXPECTED:
SGVsbG8gQ2lwaGVyQmVuY2g=

### From Hex
INPUT:
48656c6c6f
EXPECTED:
Hello

### To Hex
INPUT:
Hello
EXPECTED:
48656c6c6f   (casing may vary by implementation; CipherBench uses lowercase hex)

### URL Decode
INPUT:
https%3A%2F%2Fevil.com%2Fpath%3Fq%3Dflag%7Bx%7D
EXPECTED:
https://evil.com/path?q=flag{x}

### URL Encode
INPUT:
https://evil.com/path?q=flag{x}
EXPECTED:
https%3A%2F%2Fevil.com%2Fpath%3Fq%3Dflag%7Bx%7D
(exact percent-encoding may encode more/fewer reserved chars — path and braces should be encoded)

### Text to Binary
PARAMS: separator = space
INPUT:
Hi
EXPECTED:
01001000 01101001

### Binary to Text
INPUT:
01001000 01101001
EXPECTED:
Hi

### Reverse
INPUT:
CipherBench
EXPECTED:
hcneBrehpiC

### To Uppercase
INPUT:
Flag{mixed_Case}
EXPECTED:
FLAG{MIXED_CASE}

### To Lowercase
INPUT:
Flag{mixed_Case}
EXPECTED:
flag{mixed_case}

### Trim Whitespace
INPUT:
   padded flag   
EXPECTED:
padded flag

### Normalize Whitespace
INPUT:
too    many
  spaces	here
EXPECTED:
too many spaces here

ENCRYPTION
---------------------------------------------------------------------------

### ROT13 / Caesar  (shift = 13)
INPUT:
Uryyb PvcureOrapu
EXPECTED:
Hello CipherBench

### ROT13 / Caesar  (bruteForceAllShifts = true)
INPUT:
Uryyb
EXPECTED:
Output lists all shifts; shift 13 should show "Hello"

### XOR Cipher  (mode = single-byte, key = 0x05, bruteForce = false)
INPUT:
hello
EXPECTED after Run:
m`iij
Then run XOR again with the same key on that output — should recover:
hello

### XOR Cipher  (repeating-key, key = key)
INPUT:
abcd
EXPECTED:
Length 4 ciphertext (binary-ish). Re-run XOR with the same key to recover "abcd".

### XOR Cipher  (bruteForceSingleByte = true)
Step A — create ciphertext: paste FLAG{easy_xor_test}, XOR with key 0x42, copy output.
Step B — paste that ciphertext, enable bruteForceSingleByte.
EXPECTED:
A ranked list; top/high printable hit should include FLAG{easy_xor_test}

SOC TOOLS

INPUT:
Visit https://evil.com/path and http://bad.example
EXPECTED:
hxxps://evil[.]com/path and hxxp://bad[.]example  (or similar defang style)

### Defang / Refang  (direction = refang)
INPUT:

EXPECTED:

### PowerShell Decode  (direction = decode)
INPUT:
VwByAGkAdABlAC0ASABvAHMAdAAgACIAaABpACIA
EXPECTED:
Write-Host "hi"

### PowerShell Decode  (direction = encode)
INPUT:
Get-Process
EXPECTED:
Base64 UTF-16LE blob (long). Decode that blob again to recover Get-Process.

### JWT Decode
INPUT:
eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiJ1c2VyMSIsInJvbGUiOiJhbmFseXN0In0.-_Yjs2ecSuxDp8wRmMJSzdI2sH7f-g-jVXIN8LS_bTc
PARAMS (optional): secret = secret
EXPECTED:
Header alg HS256, payload sub=user1 role=analyst
With secret "secret": HMAC verification VALID
With secret "wrong": HMAC verification INVALID

MD5 deadbeefdeadbeefdeadbeefdeadbeef

EXPECTED:
Sections for Emails, IPv4, URLs, MD5, SHA256 — duplicates collapsed

3. Or open DevTools → Network → Disable cache → reload
4. Confirm the HTML references a hashed asset like /assets/index-*.js (name changes each build)
5. Rebuild:  docker compose up -d --build --force-recreate
6. Widen the window — Ops Chain / Arsenal / Transmit sit in a RIGHT scroll rail (side layout)
